P2 OVERVIEW

Project Overview

A mock Chocolate Sales Performance Dashboard built in Microsoft Excel using a provided 2024 sales dataset. The project transforms raw sales data into an interactive reporting solution that allows users to monitor overall performance, track sales trends and targets, identify underperforming areas, and quickly determine which chocolate brands are driving results. The project follows an end-to-end analytics workflow:
data preparation → data modeling → calculations → visualization → business insights.

P3 BUSINESS QUESTION

The Business Question

The dashboard was designed around practical business questions:
What is the company's Total Revenue?
What is the company's Profit?
Did revenue increase compared with the previous month?
By how much did revenue change?
Which areas are underperforming?
Are monthly sales achieving the assigned targets?
Which chocolate brands are performing the best?

P5 TOOLS

Tools Used

Tool Usage
Microsoft Excel Used as the primary platform for data analysis, modeling, reporting, and dashboard development.
Power Query Used to clean, transform, and prepare the provided sales dataset. The query process was designed to make updating the report easier by allowing new source files to be added to the designated folder.
Power Pivot Used to create the data model and establish relationships between the relevant datasets.
DAX Used to create measures and business calculations required for the dashboard, including revenue, profit, target achievement, and performance comparisons.
Pivot Tables & Excel Charts Used to summarize and visualize the data through KPI Cards, bar charts, column charts, and product performance analysis.
P6 IMPACT & VALUE

Impact and Value

The project demonstrates how a medium-sized sales dataset can be transformed into a structured and refreshable reporting solution rather than relying on manual spreadsheet calculations.

By organizing the dashboard around specific business questions, users can quickly monitor overall sales performance, compare results against targets, identify underperforming areas, track changes over time, and recognize top-performing products.

The project also demonstrates an important analytics workflow:

Raw Sales Data → Power Query → Power Pivot Data Model → DAX Measures → Dashboard → Business Insights

The main value is not simply presenting sales numbers, but making the information easier to interpret and act upon.
